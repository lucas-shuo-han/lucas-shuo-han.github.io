Wren Mating System Modeling Project

A grid-based agent model exploring mating system evolution through energy budget abstraction and game theory.

The Vision: Why Model Mating Systems This Way?

Mating systems—whether monogamy, polyandry, or polygyny—emerge from millions of individual decisions: Should a female accept a second male? Should a male guard one nest or seek another? Should a bird abandon a failing territory or invest more? Traditional models approach these as discrete choices, requiring complex conditional trees with dozens of parameters that quickly become intractable.

This project takes a different path. Instead of enumerating behaviors, we ask: What is the fundamental currency underlying all reproductive decisions?

The answer is energy. Time and effort invested in one activity cannot be allocated elsewhere. A female cannot simultaneously guard her nest and search for new mates; a male cannot provision two nests with full intensity. This insight leads to our core abstraction: all reproductive behaviors reduce to a single continuous variable—energy budget allocation.

By compressing a dozen discrete behaviors (mate acceptance, nest abandonment, parental care, territory adjustment) into one continuous vector, we achieve three things:

  1. Computational efficiency: Exponential reduction in parameter space
  2. Biological fidelity: Captures the true limiting factor (energy) rather than surface behaviors
  3. Generalizability: The framework applies to any organism facing time/energy constraints, not just wrens

The environment is modeled using a negative binomial distribution for resource generation, which directly parameterizes both total resource abundance and spatial aggregation—two key drivers of mating system evolution identified in the literature. This replaces arbitrary patch parameters with a mathematically tractable, statistically grounded alternative.

The Framework: A Game-Theoretic Formalization

The model is formally structured as a game with four pillars: players, strategies, payoffs, and information.

1. Players: Individuals with Energy Budgets

Agents are instantiated as female or male individuals, each occupying a position on a 500×500 grid. Every agent faces the same fundamental constraint:

search_share + Σ raising_sharek = 1.0

Where search_share quantifies investment in exploring unknown mates and territories, and raising_share quantifies investment in consolidating current reproductive units. This budget constraint reflects biological reality: energy is the true limiting factor in reproductive decisions.

2. Strategies: One Variable, Many Behaviors

All surface behaviors collapse into the raising_share vector. This is the key insight that compresses complexity:

Behavior Raising Share Representation
Monogamy vs. Polyandry Single-element vs. multi-element raising_share vector
Nest Abandonment raising_sharek = 0 for a given nest
Territory Size Adjustment Home range radius as a function of total raising_share allocated
Mate Acceptance/Rejection Male's raising_share in a nest > 0 (accepted) or = 0 (rejected)
Parental Care Intensity Directly reflected in the numerical value of raising_share

This abstraction captures the "energy limitation" as the primary biological constraint. Trade-offs between behaviors are automatically correct without manual encoding of interactions.

3. Payoffs: From Resources to Fitness

Reproductive success follows a three-stage mapping:

Stage 1: Resource Extraction

For each nest k, aggregate all participants' total investment and calculate actual acquired resources:

Rtotal,k = extract(Σ raising_sharek, positionk, resource_map)

Extraction follows distance-dependent costs—the farther from the nest center, the higher the extraction cost.

Stage 2: Logistic Conversion

Map total resources to expected surviving offspring:

fledglingsk = K / (1 + exp{-r · (Rtotal,k - R0)})

The S-shaped curve embodies: (1) diminishing marginal utility as resources saturate, (2) base mortality below threshold R₀, and (3) biological plausibility consistent with field data (Davies 1986).

Stage 3: Payoff Allocation

  • Female payoff: Sum of fledglings across all owned nests (minus egg-laying cost)
    payofffemale = Σ fledglingsk - cegg
  • Male payoff: Paternity allocated proportionally by raising_share investment
    payoffmale = Σ (raising_sharemale,k / Σ raising_sharek × fledglingsk)

4. Information: Bounded Rationality in Action

Wild animals cannot engage in infinite recursive reasoning about conspecifics' strategies, nor can they instantaneously survey entire landscapes. The model addresses this through a parsimonious two-tiered information structure:

Free Information: Global awareness of nest locations—an abstraction of territorial song, movement patterns, and spatial memory accumulated over weeks of ranging.

Costly Information: Detailed knowledge of nest composition (male/female roster, reproductive status) scales as an exponential decay function of distance and search investment:

pi = 1 - exp(-λ · search_share / di)

Where λ is the search efficiency constant, encoding vegetation density and predation risk. This parameter has direct empirical grounding: when simulating high food abundance (increasing λ via supplemental feeding), optimal search_share declines, female ranges contract, and the mating system shifts toward monogamy and polygyny—precisely matching the experimental manipulation in Davies & Lundberg (1984). Conversely, low λ values generate expansive female ranges and frequent polyandry, capturing natural variation across habitat types.

Agents form beliefs about population-level frequencies through Bayesian social learning—observing neighbor strategies and payoffs, then updating beliefs via naive Bayes. This avoids the infinite recursion problem of classical game theory: agents ask "What is the expected value of searching given population-level frequencies?" rather than "How will opponent X respond?"

My Role: Building the Strategic Core

As the lead developer of the strategy layer, I designed and implemented the entire decision-making architecture. My contributions include:

Core Algorithm Design

Raising Share Allocation: Implemented a greedy iterative optimization algorithm that allocates energy budget across nests based on marginal expected utility. At each step, the algorithm calculates marginal utility for each nest using numerical differentiation:

MUk(rk) = [ℱ(rk + ôk + Δ, pk) - ℱ(rk + ôk, pk)] / Δ

The algorithm iteratively allocates budget increments to the nest with highest marginal utility until the budget is exhausted, then normalizes to ensure constraint satisfaction. This approach prioritizes biological plausibility over mathematical optimality—future versions could substitute ML or genetic algorithms without architectural changes.

Bayesian Belief System: Designed the social learning framework where agents update search_share beliefs based on observed same-sex individuals' strategies and payoffs. The update mechanism uses descriptive statistics (average performance of neighbors) as likelihood and the agent's current belief as prior, producing a posterior that automatically contracts toward successful experience.

Code Architecture

I architected a clean, layered design with clear separation of concerns:

World Layer → Environment generation and state management Agent Layer → State entities (no decision logic) Strategy Layer → Decision algorithms (pluggable) Simulation Layer → Execution coordination

Key architectural decisions:

  • Agent-Strategy decoupling: Strategies are hot-swappable without modifying Agent code, enabling "plug-and-play" experimental design
  • Pure function interfaces: Strategies implement decide(...) → allocation, enabling unit testing with mock data and batch parallelization
  • Strong state consistency: Centralized management of cross-entity updates eliminates race conditions
  • 100% external configuration: All parameters live in config/config.py; no hard-coded values

Biological Grounding

I ensured the model maps to empirical literature:

  • The λ parameter directly corresponds to experimental manipulations in Davies & Lundberg (1984)
  • The logistic conversion parameters align with field data on Dunnock reproductive success (Davies 1986)
  • The paternity allocation assumption is grounded in behavioral ecology literature (Davies 1992)

Team Integration

The codebase is designed with clear interfaces for collaboration:

  • Standardized data output formats for analysis modules
  • Reporter module interface for team members' visualization tools
  • Type-hinted contracts that make model assumptions explicit

While this is my independent contribution, it is built to work within a larger ecosystem—other team members' analysis tools can plug in seamlessly.

Outcome: A Clean, Extensible Codebase

The final deliverable is a complete, runnable Python package with the following characteristics:

Engineering Quality

  • Fully type-hinted function signatures
  • PEP 8 compliant throughout
  • Comprehensive docstrings
  • No hard-coded parameters—all configuration externalized

Extensibility

  • Strategy modules can be hot-swapped without modifying Agent code
  • Future refinements (sex-specific detection abilities, habitat-dependent λ values) integrate without rearchitecting
  • Support for future strategy elimination mechanisms based on fitness thresholds
  • Alternative optimization criteria (risk aversion, kin selection) can be substituted without redesign

Testability

  • Strategy designed as pure function interface
  • Unit tests bypass Agent instances, directly verifying decision logic with mock data
  • Separation of concerns enables focused test coverage

Performance

  • Computational complexity: O(N) per round (reduced from O(N!))
  • Stateless Strategies allow batch parallelization without write conflicts
  • Large-scale simulations feasible on standard hardware

The repository includes debug logs as sample output, demonstrating the simulation's step-by-step execution and state transitions.
